
# AI Travel Guide 🌍

An AI-powered Travel Guide built using Python, Groq API, and Gradio.

The application accepts travel-related questions and generates recommendations using Groq's GPT-OSS 120B model.

## Features

- AI-generated travel recommendations
- Interactive web interface using Gradio
- Powered by Groq's LLM API
- Secure API key management using environment variables

## Tech Stack

- Python
- Groq API
- OpenAI Python SDK
- Gradio
- python-dotenv

## Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate into the project:

   cd YOUR_REPOSITORY_NAME

3. Install dependencies:

   python -m pip install openai gradio python-dotenv

4. Create a `.env` file and add your Groq API key:

   GROQ_API_KEY=your_actual_api_key

5. Run the application:

   python a.py

## Usage

Enter a travel-related question in the Gradio interface and receive AI-generated recommendations.
